## Descripción del proyecto

Aplicación en Python con interfaz gráfica para la predicción de **demanda eléctrica** y de **generación de energía renovable**, dentro del proyecto para Red Eléctrica de España (REE).

La aplicación permite:

- Cargar datos de series temporales desde archivos de texto (CSV).
- Crear, entrenar y validar modelos de predicción de series temporales.
- Visualizar los modelos y sus resultados.
- Obtener la métrica general de un modelo optimizado a partir de los modelos entrenados y validados.
- Guardar y cargar modelos.
- Reentrenar los modelos con datos nuevos para obtener un nuevo modelo optimizado.
